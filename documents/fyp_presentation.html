Key Code — K-Means Regime Detection
from sklearn.cluster import KMeans import pandas as pd # Compute rolling features df['rolling_return'] = df['Close'].pct_change().rolling(20).mean() df['rolling_vol'] = df['Close'].pct_change().rolling(20).std() # Fit K-Means with k=3 regimes features = df[['rolling_return', 'rolling_vol']].dropna() kmeans = KMeans(n_clusters=3, random_state=42) df['regime'] = kmeans.fit_predict(features) # Map cluster IDs → human labels using centroid analysis # Bull: high return + low vol | Bear: neg return + high vol | Sideways: rest df['regime_label'] = df['regime'].map({0: 'Bull', 1: 'Bear', 2: 'Sideways'})

LSTM Architecture
🔷 Input Layer — 7 features × 30 time steps
🔷 LSTM Layer 1 — 128 units, dropout 0.2
🔷 LSTM Layer 2 — 64 units, dropout 0.2
🔷 Dense Layer — 32 units, ReLU
🔷 Output Layer — 3 units (7/14/30-day prices)
🔷 Loss — MSE + MAE combined
🔷 Training — Early stopping, Adam optimizer
🔷 Uncertainty — Monte Carlo Dropout (50 passes)
from tensorflow.keras import Sequential from tensorflow.keras.layers import LSTM, Dense, Dropout model = Sequential([ LSTM(128, return_sequences=True, input_shape=(30, 7), dropout=0.2), LSTM(64, dropout=0.2), Dense(32, activation='relu'), Dense(3) # 7, 14, 30-day ]) model.compile(optimizer='adam', loss='mse')

Why Per-Regime SHAP Matters
🐂 Bull Market
Sentiment has highest SHAP weight. When news is positive, the model confidently predicts higher prices. EPU has low influence — macro uncertainty is less important when markets are rising.
🐻 Bear Market
EPU index has 3× higher SHAP magnitude than sentiment. During downturns, macro uncertainty (interest rates, inflation, political risk) drives the market more than news tone.
↔️ Sideways Market
RSI becomes most influential when the market is flat. Oversold/overbought signals predict the next breakout direction when price action gives no clear signal.

5 Unique Research Contributions
🗺️
1. Regime-Conditioned Forecasting for KSE-100
No prior KSE-100 paper integrates unsupervised K-Means regime labels (Bull/Bear/Sideways) directly as features into an LSTM neural network. All existing models treat every market condition identically — we do not.
📰
2. Pakistan's First Labeled Financial News Sentiment Dataset
We create the only labeled Pakistani financial news corpus. Prior KSE-100 work uses NLTK lexicons or English corpora that do not capture Pakistan's market language, economic terminology, or Urdu-inflected business English.
🔍
3. Per-Regime SHAP Analysis
Existing XAI papers apply SHAP globally across all market conditions. FinSight PK reveals which features dominate per regime — for example, that EPU index has 3× higher SHAP magnitude in bear markets vs bull markets.
🔗
4. EPU + Transformer Sentiment + Regime in One Unified LSTM
No prior model combines Pakistan's Economic Policy Uncertainty index, DistilBERT-derived daily sentiment, and K-Means regime context in a single LSTM forecasting pipeline. This is a true multimodal approach.
🌐
5. Deployed Web Application for Pakistani Retail Investors
FinSight PK goes beyond an academic paper — it delivers AI-assisted KSE-100 forecasting through a publicly accessible web interface with live sentiment feeds, real-time regime detection, and SHAP explanations in plain language.
